# Rörlighet i Göteborgs bostadsbestånd

Arbetsversion · Internt arbetsmaterial. Visas bäst i webbläsare på dator. Kontrollernas omfattning och kvarstående begränsningar beskrivs i metod-och-status.html.

Öppna index.html via webbserver. Paketet är en statisk webbplats med relativa länkar och kan läggas i en undermapp på GitHub Pages. Behåll assets/ och data/ på samma nivå som index.html. Ingen installation eller byggning krävs på servern.

Källa: SCB, specialbeställning gjord inom arbetsprojektet Agenda2030 och Jämlikt Göteborg.
